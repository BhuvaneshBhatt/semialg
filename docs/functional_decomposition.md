# Function decomposition and real conditions

Use [alggeom.decomposition](https://github.com/BhuvaneshBhatt/alggeom/blob/main/docs/guide.md) for polynomial component reconstruction, parameterized decomposition families, algebraic factor discovery and chains. `alggeom` uses `semialg` for exact parameter guards and selected real graphs.

Use [semialg.function_verification](function_verification.md) directly when the mathematical input is already a semialgebraic graph and the question concerns coverage, single-valuedness or graph composition. These operations do not require `alggeom`. See [package ownership](package_ownership.md).
