# Concepts

Concept pages explain the mathematical and architectural ideas that determine semialg's behavior. They answer **what a result means** and **why the package can certify it**. They are not API catalogs.

Use the [Guides](../guides/index.md) for task-oriented workflows and the [Reference](../reference/index.md) for signatures, return contracts, exceptions, and exact API scope.

The main conceptual threads are:

- [Exactness and certification](exactness_and_certification.md): exact representation, proof, candidates, and numerical approximation.
- [Certificate model](certificate_model.md): how proof-carrying results are represented and replayed.
- [Algorithm selection](algorithm_selection.md): how specialized and complete procedures are chosen.
- [CAD](cad.md) and [Gröbner variety CAD](groebner_variety_cad.md): decomposition models and certified specialization.
- [Representations](representations.md) and [result objects](result_objects.md): stable mathematical result semantics.

For the boundary between exact algebraization, the existing transcendental solver, and polynomial root certification, see [Transcendental and algebraic solving scope](../guides/transcendental_scope.md).
