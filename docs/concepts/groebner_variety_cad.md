# Gröbner variety CAD

Gröbner variety CAD is an exact specialization for semialgebraic formulas whose satisfying points must lie on a finite polynomial variety. It combines an equality-ideal Gröbner basis with CAD-style cylindrical lifting instead of constructing a full sign-invariant decomposition of all of real space.

## When it applies

For a formula with polynomial equalities that are logically common to every Boolean branch, semialg forms their equality ideal. The specialized backend is eligible only when exact ideal analysis proves that the ideal is zero-dimensional. Positive-dimensional ideals, formulas without common equalities, unsupported coefficient domains, and operations that need the omitted sectors use complete CAD instead.

Two syntactically different equalities can represent the same constraint. Common equalities are normalized up to a nonzero polynomial scalar, so `x + y == 0` and `-2*x - 2*y == 0` are recognized as the same zero set.

## Projection from the equality ideal

The equality ideal is first represented by an exact Gröbner basis. Its leading monomial ideal gives the exact algebraic dimension. For a zero-dimensional ideal, semialg counts the quotient-algebra dimension without materializing all standard monomials.

The CAD variable order is then used to request a lexicographic basis through FGLM. This produces triangular relations suitable for cylindrical lifting. For example, the system

```text
x - y = 0
x**2 + y**2 - 2 = 0
```

can be represented in lifting order by relations equivalent to

```text
x**2 - 1 = 0
y - x = 0
```

Coordinate eliminants are diagnostic metadata and are computed lazily. Normal lifting needs the triangular basis, not a separate FGLM conversion for every coordinate.

## Compatible-section lifting

Coordinate roots cannot be combined by Cartesian product. For

```text
x**2 = 1
y**2 = 1
x*y = 1
```

both coordinates individually have roots `-1` and `1`, but only the points `(-1, -1)` and `(1, 1)` satisfy the complete ideal.

At each lifting level semialg specializes the active triangular relations at the already chosen algebraic sample, isolates the candidate roots, and retains only roots that satisfy every active equality exactly. Residual inequalities are reduced modulo the equality ideal and evaluated as soon as all variables they need are bound.

## Variety sub-CAD versus complete CAD

The resulting object is a **variety sub-CAD**. It is exact for the requested formula on the common equality variety, but it is not a partition of the whole ambient real space. Accordingly, its internal `complete` flag is false even when the returned solution formula is exact.

This distinction matters for operations such as topology and universal quantification. A universal statement ranges over omitted sectors as well as equality sections, so universal or mixed quantifier prefixes use complete CAD. Pure existential elimination can use the finite-variety backend when the common equalities are required by the matrix.

## Exact fallback contract

Failure of an exact algebraic operation is never interpreted as mathematical falsehood. If a specialized fiber cannot be constructed, a root sign cannot be certified, or another required exact lifting operation is unsupported, the variety backend declines and semialg restarts with complete Collins CAD.

This is the central correctness contract:

```text
exactly false      -> reject the branch
cannot certify     -> abandon the specialization and use complete CAD
```

## Diagnostics

Use `return_result=True` to inspect which backend was selected.

```python
import sympy as sp
from semialg import cad

x, y = sp.symbols("x y", real=True)
formula = sp.And(sp.Eq(x - y, 0), sp.Eq(x**2 + y**2, 2), x > 0)

result = cad(formula, (x, y), return_result=True)

result.cad.backend
# 'groebner-variety'

result.diagnostics["variety_only"]
# True

result.diagnostics["equality_dimension"]
# 0

result.diagnostics["quotient_dimension"]
# 2

result.formula
# Eq(x, 1) & Eq(y, 1)
```

To request a full-space decomposition for comparison or for an operation that needs all sectors:

```python
full = cad(formula, (x, y), strategy="collins", return_result=True)
full.cad.backend
# 'collins-complete'
```

A positive-dimensional equality set falls back automatically:

```python
formula = sp.And(sp.Eq(x**2, 0), sp.Eq(x * y, 0), y > 0)
result = cad(formula, (x, y), return_result=True)
result.cad.backend
# 'collins-complete'
```

## Quotient dimension and real point count

Quotient dimension counts algebraic multiplicity, not distinct real points. The ideal generated by `x**2` has quotient dimension two but only one geometric real point, `x = 0`. The lifting code therefore isolates compatible real sections rather than treating quotient dimension as a real-solution count.
