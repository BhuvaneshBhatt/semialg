# API overview

Use the [task guide](guides/choosing_an_api.md) to choose an operation, the [primary reference](reference/index.md) for public signatures and return contracts, and the [expert index](reference/expert_api.md) for specialist namespaces. The [package ownership table](package_ownership.md) identifies the canonical home of each mathematical operation.

The root namespace contains primary user operations. Internal algorithm helpers and expert APIs stay in their owning submodules. The [feature matrix](feature_matrix.md) and [limitations](limitations.md) define supported cases; an API's existence alone is not a claim of general completeness.
