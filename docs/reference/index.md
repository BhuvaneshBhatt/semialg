# Reference

Reference pages specify public contracts: signatures, accepted inputs, return contracts, certification semantics, exceptions, and supported exact domains. They are terse about mathematical motivation.

For mathematical background, use the [Concepts](../concepts/index.md). For worked workflows, use the [Guides](../guides/index.md). The [Everyday API](everyday_api.md) is the recommended discovery surface. The [Public API](public_api.md) is the complete curated root index, while the family pages provide the substantive contract for each API group.
