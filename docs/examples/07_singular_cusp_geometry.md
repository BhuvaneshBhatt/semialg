# Singular locus, tangent space, and exact tangent cone

Analyze the cusp y²=x³ at its singular point.

## Problem and interpretation

For the cusp \(y^2=x^3\), the Jacobian vanishes at the origin, so the Zariski
tangent space is all of \(\mathbb R^2\). That tangent space is larger than the
actual limiting first-order geometry.

The exact ideal-theoretic tangent cone is generated by \(d_y^2\), so its
underlying direction set is the \(x\)-axis. `tangent_cone` obtains this through
the saturated \(m\)-adic deformation construction rather than by taking the
lowest term of each input generator independently.

## Executable example

```python
import sympy as sp

from semialg import singular_locus, tangent_cone, tangent_space

x, y = sp.symbols("x y", real=True)
f = y**2 - x**3

singular = singular_locus([f], [x, y])
space = tangent_space([f], {x: 0, y: 0}, [x, y])
cone = tangent_cone([f], {x: 0, y: 0}, [x, y])

print(singular)
print(space)
print(cone)

assert space.dimension == 2
assert cone.certified is True
assert cone.ideal_generators == (cone.direction_variables[1] ** 2,)
```
