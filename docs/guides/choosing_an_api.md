# Choosing an API

| Goal | API family | Check before interpreting the answer |
| --- | --- | --- |
| Feasibility, implication or equivalence | `decision` and primary decision functions | Variable scope, assumptions, exact decision provenance |
| Eliminate unknowns and retain parameter conditions | `qe` | Quantifier order, coefficient poles and exceptional strata |
| Image, range or optimization | Region/range/optimization APIs | Input domain, attainment and side-condition certificates |
| Existence and uniqueness of graph outputs | `function_verification` | Selected branches and denominator exclusions |
| Finite equality-only solving | algroots | Finite algebra dimension versus point count |
| Schemes, normalization and decomposition search | alggeom | Field-relative geometry, map domain and completeness scope |

Follow [worked applications](../worked_applications.md) for complete scripts, [parameterized computation](parameterized_computation.md) for guarded fibers, and [the reference](../reference/index.md) for signatures. A returned unsupported/unknown result or exhausted bound does not establish a mathematical negative.
